# HASHPASS LiveOps

**The autonomous realtime operating system for physical events.**

Physical event teams coordinate live problems across scanners, radios, messaging apps, and spreadsheets. HASHPASS LiveOps converts those signals into evidence-backed incidents, constrained recommendations, human-approved actions, and verified outcomes while the event is happening.

The primary user is an event operations manager. The prototype targets the Burning Token Convex — Realtime challenge, subject to classified-brief verification documented in [BASELINE](./BASELINE.md). Current implementation status: local deterministic operator experience and complete Convex operational-plane source are implemented; public Convex configuration, judge deployment, and stakeholder validation remain pending.
