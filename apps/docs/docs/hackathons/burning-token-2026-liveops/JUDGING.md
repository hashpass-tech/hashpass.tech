# Judging evidence map

| Dimension | Evidence |
| --- | --- |
| Problem | Fragmented physical-event operations and a specific operations-manager user |
| Product | Signal → incident → recommendation → approval → action → verified result |
| Execution | New app within an established event platform; auditable base commit and Convex model |
| Validation | Pending; protocol exists and no feedback is fabricated |
| Experience | Desktop console, visible state transitions, reproducible controls, privacy labels |
| Demo | Gate congestion hero flow plus pass and speaker breadth scenarios |
