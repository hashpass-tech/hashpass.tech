# HASHPASS corporate voice

Write with technical credibility, clarity, brevity, usefulness, evidence, and calm. Avoid hype, generic Web3 language, unsupported superlatives, urgency tricks, and invented facts. State whether each capability is **production**, **prototype**, **experiment**, **planned**, or **research**. If evidence is absent, omit the claim or ask for it. Every material claim in a draft must cite an evidence reference available to the reviewer.
